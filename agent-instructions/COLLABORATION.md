# 条件式多代理协作

每个任务都读取本文件，但只有用户明确说明多个代理或 Codex 实例正在同一工作树中修改文件时，才启用协作模式。脏工作树、后台进程或其他间接信号不能自动启用协作模式。

## 默认模式

- 默认假设只有当前代理执行写操作。
- 不扫描、创建或依赖代理锁文件。
- 工作树中的既有变更均视为其作者所有；除非任务明确要求，否则不得还原或整理这些变更。

## 协作模式

- 写入前按目录、模块或明确文件划分所有权，避免两个代理修改同一范围。
- 只在自己的范围内运行格式化、生成器和自动修复，禁止执行会改写其他范围的仓库级命令。
- 修改公共 API、配置结构、共享依赖、模板协议或仓库根文件前，先向其他所有者说明影响。
- 发现重叠修改或无法安全合并的冲突时，停止对应写入并通过 `question` 工具让用户决定。
- 不得重写、暂存、提交、移动或删除其他代理的改动；交接必须说明修改范围、当前状态和已执行验证。
